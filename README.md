# Mein Gartenkalender

Pflege-App für meinen Garten. Startseite mit zwei Bereichen:

- **Blumenbeet:** monatliche Aufgaben (Schnitt, Düngen, Winterschutz), Pflanzenliste und Krankheiten für Stauden, Sträucher, Rosen, Palmen.
- **Hochbeet:** Tomaten, Gurken, Zucchini, Paprika mit allen Sorten, Monatsaufgaben von Aussaat bis Ernte und einem Ratgeber zu Krankheiten (mit Fotos) und Tipps.

Live: https://mein-gartenkalender.netlify.app
